🚀 快速开始

点右上角 ＋ 打开记账表单
  1. 打开 ⚙️ 设置，添加同行成员。
  2. 点右上角 ＋ 记一笔。
  3. 先选付款人。
  4. 再选公开或私密。
  5. 然后勾选费用参与人。
  6. 填写金额、币种、分类和时间。
  7. 保存，完成。
记账表单顺序：付款人 → 可见性 → 参与人 → 金额分类

顶部两个大页签：个人开销 看每个人花了多少；费用明细 看全部账单和结算方案。

🔒 公开与私密账单

公开账单

  • 所有人可见。
  • 参与人均摊。
  • 计入结算。

私密账单

  • 仅创建人和被选参与人可见。
  • 不参与均摊与结算，视为自付。
  • 不参与结算，因此没有「完成」标记。
  • 计入个人开销统计。
  • 列表中以淡紫色底显示。
  • 选私密时，参与人默认只有自己。

📊 个人开销页

点扇区或图例筛选分类；下方页签筛选公开/私密

成员页签

  • 顶部胶囊页签切换成员。
  • 「全部」：全员公开账单，按全额统计。
  • 成员页：该成员作为付款人或参与人的账单，按份额统计。

图表联动

  • 点环形图扇区或图例，只看某一分类。
  • 再点一次取消筛选。
  • 图表下方的「全部 / 公开 / 私密」页签快速筛选账单类型。

金额口径

  • 成员页右侧金额是该成员的份额。
  • 同时显示原币金额和人民币折算。
  • 全部页右侧金额是账单全额。

💸 费用明细与结算

  • 账单按付款时间倒序排列。
  • 多选账单可「标为完成」，已结清的账不再参与结算。
  • 点对点明细：每两个人之间的净欠款。
  • 最短转账路径：用最少转账次数结清所有人的方案。
  • 以上两项都不含私密账单和已完成账单。

💱 汇率

更新失败时先点「诊断」测试网络连通性
  • 每天首次打开 App 自动联网更新一次。
  • 数据源每日 T+1 发布：今天拿到的是前一交易日的汇率。
  • 外币一律按付款当天的汇率折算人民币。
  • 没有当天快照时，用最近一天的汇率。
  • 管理员可在 ⚙️ 设置-汇率里手动修改。
  • 点汇率页脚的「立即更新」可强制刷新。

👥 多人共享

创建与加入

创建房间后，把邀请链接发给同伴
  • ⚙️ 设置 →「开启共享 · 创建房间」。
  • 把邀请链接发给同伴。
  • 对方打开链接即加入，数据实时同步。

身份与权限

  • 加入后先选择「我是谁」。
  • 你记的账会标记创建人。
  • 你只能修改自己的记录。
  • 管理员可修改所有记录。

管理密钥

  • 只保存在创建者的设备上。
  • 换设备时凭它恢复管理员身份。
  • 不要发到群里。

🗺️ 多行程

新增与切换

  • ⚙️ 设置 → 我的行程 →「新增」。
  • 新行程是全新的空账本，数据完全独立。
  • 点行程名即可切换。

删除

点「删除」后，每个行程右上角出现小叉
  • 点「删除」，每个行程右上角出现小叉。
  • 管理员删除：连同云端数据一起删除，不可恢复。
  • 普通成员删除：只是从本机移除。

🔗 把一个干净的账本发给朋友

不需要你替他创建。

  1. 复制不带 #trip= 后缀的首页链接。
  2. 把链接发给朋友。
  3. 他打开后是全新的单机账本。
  4. 他自己点「新建行程」，即创建属于他的房间。

管理密钥只保存在他的设备上，你们的数据互不可见。注意不要把你自己设置页里的「邀请链接」发给他，那会加入你的账本。

💾 数据管理

都在 ⚙️ 设置底部。

  • 导出 CSV：随时备份，Excel 可直接打开；你看不到的私密账单不会导出。
  • 导入：用之前导出的 CSV 整体替换当前数据，仅管理员可用。
  • 载入示例：一键填入演示数据体验功能。
  • 清空：删除全部数据，不可恢复。

❔ 常见问题

看不到自己刚记的私密账？

先在设置里选好「我是谁」。私密账单只对创建人和参与人可见。

汇率没更新？

每天只自动更新一次。网络偶发失败时，第二天打开会重试，也可以点汇率页脚的「立即更新」。仍失败时点旁边的「诊断」，可分别测试汇率源和云同步接口的连通性。

改完数据别人没同步？

同步有不到 1 秒的防抖。对方页面在后台时暂停轮询，切回前台即会拉取最新数据。

换手机了？

用邀请链接重新加入房间并选择身份。需要管理员权限时，再输入管理密钥。

我是谁？
选择你的名字，之后你记的账会标记创建人，只能修改自己的记录
